# Code of Conduct

We welcome contributors regardless of background, experience, identity, or affiliation. Help make this project a useful and respectful place to work.

## Expected behavior

- Discuss ideas and code without attacking people.
- Give specific, constructive feedback and accept corrections in good faith.
- Respect privacy, consent, and the time of volunteers.
- Make room for new contributors and different perspectives.

Harassment, threats, discrimination, sexualized conduct, doxxing, and deliberate disruption are not acceptable. Do not publish private correspondence or personal information without permission.

## Scope and enforcement

These expectations apply to project issues, pull requests, discussions, and other spaces maintained for this project. Maintainers may edit or remove content, close discussions, restrict participation, or block accounts when needed. Enforcement should be proportionate to the behavior and its impact.

For a conduct concern, contact a maintainer privately through a contact method they publish on their GitHub profile. If no private method is available, open a brief issue requesting a private contact channel without identifying affected people or including sensitive details. Security vulnerabilities should use the separate process in SECURITY.md.
